# 📊 Книги спинов (`books-seeds.txt`)

Единственный файл данных для слота в браузере — **`books-seeds.txt`** (формат **`BOOKS_SEEDS_V2`**). Слот **не** загружает `books.json`.

## Как считаются исходы при генерации

Модуль **`bonus-slot-sim.js`** повторяет в Node ту же цепочку, что **`slot.js`** после остановки барабанов (без DOM и без анимаций):

1. **Базовый спин:** выпадение символов как на базе → **split в нижнем ряду** (удвоение верхних рядов, `split_wilds`, учёт в окошках только в бонусе) → **все xWays** заменяются одним случайным payable-символом и множителем **2–7** от **`randomInt`** → при ровно **2 scatter** мини-игра «два скаттера» (те же пулы символов и множители).
2. **Бонусные фри:** **`generateResult` для бонуса** (`slot.js`): нижний ряд на окошках из пула high/wild/xWays/split, без scatter по весам, затем те же шаги split → xWays → два скаттера; **`bonusEnhancerMults`** живёт между фри как в слоте.

Константы **`SCATTER_WEIGHT`**, **`XWAYS_REDUCTION_FACTOR`**, **`WILD_REDUCTION_FACTOR`** и массив **`SYMBOLS`** в **`generate-books.js`** выровнены со **`slot.js`**.

Запись в файл — это **финальные** поля после всей цепочки (индексы **`0 … index(split_wilds)`**, то есть включая **`split`** и **`split_wilds`**).

В **`slot.js`** при входе в бонус с базового спина **из книги**: если есть **полный хвост** фри (7 / 8 / 10 по числу скаттеров на базе), фри проигрываются **из файла**. Иначе — RNG слота. При воспроизведении из книги по-прежнему **отключены** апгрейды scatter до 4/5 скаттеров **внутри** бонуса (+спины), чтобы не расходиться с зафиксированной длиной серии в строке.

## Формат `BOOKS_SEEDS_V2`

Строки с `#` — комментарии; в шапке **`RTP_ALL_SEEDS`** и **`RTP_BASE_SPIN_ONLY`**.

**RTP:** `totalBet = число_книг × spinCostMult` (только платный спин). **Фри-спины в totalBet не входят** (ставка 0). `totalWin` — сумма колонки `total_win@1` (база + бонус при bet=1). Целевой RTP при генерации: **96%** (подгонка заменой части книг).

**Hit rate (только `books-seeds.txt` и `mod-scatter1`):** **26%** книг с `total_win@1 > 0`, **74%** с **0×** (нет линий и нет бонуса в строке). В шапке: `HIT_RATE`. Команда: `node generate-books.js --hit26` или `--base-mod`.

Рабочая строка — **TAB-разделённые колонки**:

| Колонка | Смысл |
|--------|--------|
| 1 | `seed` — строковый идентификатор |
| 2 | **total_win** при ставке **1.0**: базовый спин + вся бонуска (если была), одна сумма на весь seed |
| 3 | `has_bonus`: `1` если на базовом поле было ≥3 scatter при генерации книги |
| 4 | Барабаны базового спина: **5 групп** через `\|`, в группе **3 индекса** через запятую (ряды сверху вниз) |
| 5 | Веса ways базового спина: так же **5×3** |
| 6+ | **Только если был бонус на базе:** колонка `N` = число фри (`7`, `8` или `10`), затем на каждый фри **три** колонки: финальные **барабаны**, **веса**, **landing** (поле сразу после остановки, до split/xWays) |

Индексы совпадают с **`SYMBOLS`** в **`slot.js`** / **`generate-books.js`**: от `low1` до **`split_wilds`**.

## Файлы

- **`books-seeds.txt`** — базовые спины (префикс `rv_`).
- **`books-seeds-mod-scatter1.txt`** — мод «1 scatter», ставка **1.2×** (префикс `rvm1_`). `node generate-books.js --mod-scatter1`
- **`books-seeds-buy-scatter3.txt`** — покупка бонуса, **ровно 3** scatter, ставка **68×** (префикс `rvb3_`). `--buy-scatter3`
- **`books-seeds-buy-scatter4.txt`** — **4** scatter, **140×** (`rvb4_`). `--buy-scatter4`
- **`books-seeds-buy-scatter5.txt`** — **5** scatter, **522×** (`rvb5_`). `--buy-scatter5`

Команды:
- `--everything` — все 5 файлов с подгонкой RTP 96%
- `--buy-all` / `--all` — как раньше
- `--adjust-rtp-only` — подогнать RTP в уже существующих файлах (без полной перегенерации)
- `--recalc-headers-only` — только пересчитать шапку RTP (формула totalBet без фри)
- `--no-rtp-adjust` — генерация без подгонки
- `--rtp-target=96` — другой целевой RTP (%)
- **`bonus-slot-sim.js`** — симуляция RNG как в слоте (split / xWays / два скаттера / бонус).
- **`generate-books.js`** — сбор книг и RTP-отчёт, запись `books-seeds.txt`.
- **`slot.js`** — загрузка и воспроизведение.

## Запуск

```bash
node generate-books.js
```

После этого открой слот через любой статический сервер из корня проекта (например `npx serve .`), чтобы браузер мог прочитать `books-seeds.txt`.
