📊 ИНФОРМАЦИЯ О КНИГАХ

Каждая книга содержит:
```json
{
  "id": 0,                    // Уникальный ID (0-99999)
  "hasBonus": false,          // Есть ли бонусная игра
  "scatterCount": 0-5,        // Количество скаттеров
  "spin": {                   // Результат базового спина
    "reel0": [idx, idx, idx],
    "reel1": [idx, idx, idx],
    "reel2": [idx, idx, idx],
    "reel3": [idx, idx, idx],
    "reel4": [idx, idx, idx],
    "weights": [...],
    "win": 0.37               // Выигрыш от спина
  },
  "bonusSpins": [...],        // (Только если hasBonus=true)
  "bonusWin": 12.45,          // (Только если hasBonus=true)
  "totalWin": 12.82           // Всего: спин + бонус
}
```

🎮 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

### Пример 1: Обычный спин (без бонуса)
- Вводите ID: 0
- Система проигрывает спин
- Результат отображается в консоли: "[ОТЛАДКА] Проигрываю книгу #0"

### Пример 2: Спин с бонусом
- Вводите ID одной из 198 книг с бонусом (например: 1000, 5000, 50000)
- Система проигрывает:
  1. Базовый спин с 3+ скаттерами
  2. Открывается бонусная игра
  3. Проигрываются 7-10 фри спинов (в зависимости от количества скаттеров)
  4. Показывается общий выигрыш

### Пример 3: Проверка вероятностей
- Проигрывая разные книги, вы можете проверить:
  - Как часто выпадают выигрыши
  - Как часто выпадают бонусы
  - Реальный РТП

🎯 СЛУЧАИ ИСПОЛЬЗОВАНИЯ

1. **Проверка честности**
   - Проиграйте несколько случайных книг (ID 0, 1000, 50000 и т.д.)
   - Проверьте соответствие выигрышей таблице выплат

2. **Проверка бонусов**
   - Найдите книги с бонусом (ID с hasBonus=true)
   - Проверьте, что бонусные спины проигрываются правильно

3. **Демонстрация**
   - Проиграйте специфичные книги в присутствии регулятора
   - Документируйте результаты

4. **Отладка**
   - Если есть проблема с конкретным спином
   - Проиграйте его по ID для проверки
